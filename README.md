## 📖 Introduction

This repository documents a complete, practical journey through **IBM SPSS Statistics**, from entering your first dataset to running regression, ANOVA, and factor analysis like a researcher.

Each module includes:
- 📝 **Notes**: a clear explanation of the concept and when to use it
- 📁 **Dataset**: a sample `.csv` / `.sav` file to practice with
- 🧮 **Syntax**: the SPSS syntax (`.sps`) behind the point-and-click steps
- 📊 **Output**: SPSS output tables/charts as PDF or screenshots
- 🧠 **Interpretation**: what the numbers actually mean, in plain language

## 📂 How to Use This Repo

Each day lives in its own folder, named `DayXX-Topic-Name/`, containing:
- `DayXX-Notes.md`: theory and explanation
- `dataset.csv` / `dataset.sav`: the practice data
- `syntax.sps`: SPSS syntax file
- `output.pdf`: SPSS output tables/charts
- `interpretation.md`: plain-language explanation of results

Clone the repo and explore any day:

```bash
git clone https://github.com/HereIsMuhammad/spss-statistics-course.git
cd spss-statistics-course
cd Day21-Regression-Exam-Scores
```
